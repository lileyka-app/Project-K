# Оновлення довідки до 1.4 — план (DOCS-03)

Робочий файл гілки `docs/update-1-4`: на сайт не йде (`sync-docs` бере лише `docs/user`, `docs/dev` і
перелічені кореневі документи). **Прибрати перед злиттям у `main`.**

Довідка востаннє звірялась із кодом на 1.3.1. Аудит 2026-11-20 пройшов усі 52 сторінки (`docs/user`,
`docs/dev`, self-host, експлуатація) проти `release-1.4` (`2a795f69` = `main` `474812f4`). Висновки:

- **Усі PNG у `docs/user/images` зняті до 1.4.** Бічне меню, налаштування, реєстр, картка, шапки
  сторінок змінились, тож переважна більшість скрінів — перезйомка.
- Рівні (як в аудиті 2026-10-12: 1 — зрозуміло й актуально, 2 — доробити, 3 — суттєво застаріло,
  4 — немає): рівень 1 — 1 сторінка (`report-problem`), рівень 2 — 22, рівень 3 — 22, рівень 4 —
  11 нових сторінок для користувача й 6 для розробника.
- Теми 1.4 без жодної сторінки: старші курені, переходи й запрошення, теги, архів і небезпечний
  режим, картка за посиланням і QR, Пластовий життєпис, третя проба як окрема сторінка, налаштування
  куреня (пʼять блоків), імпорт складу, код `PL-`.

## Етап 0 — інструменти рев'ю (зроблено)

- Мітки сторінок у frontmatter: `status: new | updated | deprecated | removal`, `since: '1.4'`.
  Мітка — у бічному меню й біля заголовка; у прод іде лише те, що в `site/src/doc-status.ts` має
  `prod: true` («Нове», «Застаріле»).
- Режим рев'ю під `npm run dev`: змінені блоки (абзац, пункт списку, таблиця, картинка) на тлі
  `accent-50` з «Як було», прибране закреслене, `/review` — перелік змін із позначкою «вичитано».
  База — `origin/main`, тобто те, що вже на сайті.
- Правила — CONTRIBUTING «Сайт і довідка», як користуватись — `site/README.md`.

**Як вичитувати:** `cd site && npm run dev` → http://localhost:4321/review → кожна сторінка зі списку,
змінене — на теплому тлі, «Як було» — поруч. Нові сторінки підсвітки не мають: їх читати цілком.

## Як пишемо

| Вид сторінки | Тека | Для чого | Форма |
|---|---|---|---|
| Функція | `features/` | що це, хто що може, як влаштовано | короткий вступ → таблиця прав → розділи по частинах екрана → «На телефоні» → «У старшому курені» |
| Як зробити | `howto/` | одна задача людини | нумеровані кроки, скрін на крок, де людина клацає; результат наприкінці; виноски `:::caution` для незворотного |
| За роллю | `roles/` | що робить ця людина | огляд із посиланнями на функції й how-to, без повторення кроків |
| Початок | `start/` | перші хвилини | коротко, з посиланнями |

- Мова — українська, на «ти», коротко; заборонені слова — `ukrainian-wording` («володілець», «уряд»,
  «посада», «невірний»). Назви кнопок і пунктів — дослівно з інтерфейсу, у «лапках».
- **Старший курінь** не дублює сторінки: у кожній функції, де є різниця, — розділ або виноска
  `:::note[У старшому курені]`, а повна картина — на сторінці «Старший курінь».
- **Діаграми** (mermaid, рендер і зум уже є): переходи між куренями (послідовність), етапи третьої
  проби (потік із двома бічними станами), небезпечний режим архіву (послідовність), хто бачить
  картку (дерево рішень). Діаграма — там, де є кроки між двома людьми чи стани; не для того, що
  видно на одному скріні.
- **Скріни** — з dev-стеку через `todo/docshots` (README там): веб 1280 px світла тема, телефон —
  Pixel 7; дані — курінь УПЮ 1 і старший курінь «Орден Хрестоносців» з dev-сіду. Підпис під скріном
  каже, що на ньому, а не що робити.
- Нова сторінка дістає `status: new`, `since: '1.4'` (знімається на 1.5). Сторінка, яку
  переписано, мітку не дістає: «Оновлено» рахує рев'ю саме.
